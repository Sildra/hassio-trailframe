# Changelog

All notable changes to this app will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/).

Versioning follows Trailframe releases: `X.Y.Z-A`, where `X.Y.Z` matches the
packaged Trailframe version and `A` is the revision of the app itself.

## 0.1.0-1

- Initial release
- Packages Trailframe 0.1.0 from PyPI (installed into a persistent virtualenv
  on first start)
- Image is built locally by the Supervisor on install (no published images)
